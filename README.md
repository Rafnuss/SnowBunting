# Snow Bunting

This repository contains the raw data and the trajectory information generated with the GeoPressureR workflow from 4 multisensor data loggers, equipped on male snow buntings&nbsp;<em>Plectrophenax nivalis</em> in Adventsdalen, Svalbard, in 2017 and 2018.
